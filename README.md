# Tõenäosuste skaala

Eesmärk: Luua loend sündmustest koos nende tõenäosustega, mis aitab inimestel mõista tõenäosust.

## Käitamine

1. Hangi andmed: `python andmed/hangi_andmed.py`
2. Loo joonised: `python joonised/loo_joonised.py`

## Projektis struktuuri

- `andmed/hangi_andmed.py` - Andmete kogumine ja tõenäosuste arvutamine
- `joonised/loo_joonised.py` - Jooniste tegemine
- `joonised/` - Väljundid (JSON, CSV, kujutised)
